# Python Mega Course Projects

Welcome to my repository for the Python Mega Course projects! This course covers a wide range of Python applications, from data visualization to web development, and even building full-fledged desktop applications. Below is a summary of the projects included in the course, and will be updated with changes

## Projects Overview

### 1. Plotting Volcano Locations on the US Map
This project involved plotting the locations of volcanoes on a map of the United States using Python. I learned how to use libraries like Folium to create interactive maps that can be embedded in web applications.

Technologies: Folium, Pandas

### 2. Making a Motion Detector/Tracker

I built a motion detector that tracks movement using a webcam or video feed. The project involves image processing and computer vision techniques to detect and highlight movement in real-time, and writes to a .csv file

Technologies: Python, OpenCV

### 3. Simple Data Visualization with Bokeh and Matplotlib

I explored the basics of data visualization by creating simple yet powerful plots using Bokeh and Matplotlib. I learned how to visualize data trends and patterns effectively, including summary statistics

Technologies: Python, Bokeh, Matplotlib, Pandas

### 4. Personal About Me Website

I created a personal website using Python’s Flask framework. This project covers the basics of web development, including routing, templates, and deploying a simple website.

Technologies: Python, Flask, HTML, CSS

### 5. Book Database

I developed a book database application where users can add, search, and manage books. This project involves working with a postgreSQL database, building a user-friendly interface, and performing CRUD operations.

Technologies: Python, postgreSQL, Tkinter, Flask

### 6. Web Scraper to Find House Prices

I learned how to scrape data from the web with a project that fetches real estate prices from websites. The project demonstrates how to parse HTML, handle HTTP requests, and store the data for further analysis.

Technologies: Python, BeautifulSoup, Selenium, Pandas, Requests

### 7. User Data Collection and Email Statistics

I built a website that collects user data through a form and sends them an email with personalized statistics. This project covers form handling, data processing, and sending emails via SMTP.

Technologies: Python, Flask, Pandas, smtplib

### 8. Geocoding Addresses from a CSV File

I created  a web application that processes addresses from a CSV file and returns their respective geographic coordinates (longitude and latitude). The project introduces geocoding techniques using the Geopy library.

Technologies: Python, Flask, Geopy, Pandas

### 9. Word or Acronym Definition Finder

I developed a command-line application or a web service that finds definitions of words or acronyms. The project involves querying APIs or databases to fetch and display the definitions.

Technologies: Python, Requests, 

### 10. Website Blocker During Work Hours

I built a productivity tool that blocks distracting websites during specified work hours. This desktop application modifies the system’s hosts file to redirect blocked sites to a non-existent server.

Technologies: Python, OS

### 11. Stock Analysis Dashboard

Create a stock analysis dashboard that displays candlestick charts for any ticker symbol. This project involves fetching stock data from an API, processing it, and visualizing it using Bokeh.

Technologies: Python, Bokeh, Pandas, Flask (optional)
